# CHK001 — ticket text format pick

Same ticket ("Innnes SSO"), two styles. Both go through `ticket_text::markdown_to_adf`
(headings → ADF heading, `-` → bulletList, `- [ ]` → taskList, text → paragraph).

## Sample 1 — fixed sections

```markdown
## Background
Innnes wants staff to sign in to the portal with their Microsoft accounts.

## Goal
Single sign-on via Entra ID for the Innnes portal.

## Tasks
- [ ] Register the app in Innnes's Entra tenant
- [ ] Add OIDC login to the portal
- [ ] Test with two Innnes test users

## Acceptance criteria
- Staff log in with their work account
- Local passwords are no longer needed

## References
- None
```

## Sample 2 — lean, sections only when they have content

```markdown
Add Microsoft (Entra ID) single sign-on to the Innnes portal so staff log in with their work accounts instead of local passwords.

## Tasks
- [ ] Register the app in Innnes's Entra tenant
- [ ] Add OIDC login to the portal
- [ ] Test with two Innnes test users

## Done when
- Staff log in with their work account
- Local passwords are no longer needed
```

## Pick

Sample 2. Reason: matches D-08 (no fixed template, sections only when they have
content, length scales with the task) — Sample 1 forces empty sections like
"References: None". Picked under `/flow:next --finish` pre-approval; the Owner can
swap the guide in `skills/worklog/references/jira.md` later.
