# CHK004 — pin end to end (sandbox)

Ran `bash $CLAUDE_JOB_DIR/tmp/chk004.sh` (exit 0): the real `worklog` debug binary built from this branch, against a throwaway `WORKLOG_HOME`. `sync --dry-run` builds the same Tempo lines (`lines_for_day` → `effective_seconds`) that the web UI's Tempo line reads through the daemon.

Shows: pin before any block → 1800s sent; re-pin to 1 → 3600s; 0.4 refused, nothing written; `--clear` leaves 0 override rows; an unpinned non-APRÓ 10-min line → 1800s (FR-02).

Not checked: the live loop (Claude in a real session told "put 0,5h on this ticket", then the web UI in a browser). `scripts/install-local.sh` installs main or a PR and replaces the Owner's running daemon, so it was not run unattended. Do it after merge.

```bash
#!/usr/bin/env bash
# CHK004 sandbox run: real CLI binary against a throwaway WORKLOG_HOME.
set -u
REPO=/Users/tomas/Desktop/Projects/worklog/.claude/worktrees/pin-ticket-hours
W=$REPO/rust/target/debug/worklog
export WORKLOG_HOME=/Users/tomas/.claude/jobs/8324ea2a/tmp/chk004
rm -rf "$WORKLOG_HOME"; mkdir -p "$WORKLOG_HOME"
D=2026-10-15
DB=$WORKLOG_HOME/worklog.db

echo '$ worklog db migrate   (fresh sandbox WORKLOG_HOME)'
$W db migrate; echo "exit $?"
echo '$ sqlite3: cache Jira issue ids for ACME-7 / ACME-8 (dry-run needs them, no network)'
sqlite3 "$DB" "INSERT INTO jira_tickets (key, summary, issue_id) VALUES ('ACME-7','',  '1007'), ('ACME-8','','1008');"; echo "exit $?"
echo '$ worklog ticket hours ACME-7 0,5 --day 2026-10-15   (pin BEFORE any block exists)'
$W ticket hours ACME-7 0,5 --day $D; echo "exit $?"
echo '$ sqlite3: 10-min block on ACME-7 (pinned) and 10-min block on ACME-8 (unpinned, no Mirres row)'
sqlite3 "$DB" "INSERT INTO blocks (day, jira_issue, started_at, ended_at, duration_seconds, description) VALUES ('$D','ACME-7','${D}T09:00:00Z','${D}T09:10:00Z',600,'pinned work'),('$D','ACME-8','${D}T10:00:00Z','${D}T10:10:00Z',600,'short work');"; echo "exit $?"
echo '$ worklog sync --day 2026-10-15 --dry-run --json   (timeSpentSeconds per ticket)'
$W sync --day $D --dry-run --json | grep -E '"(timeSpentSeconds|issueId|status|reason)"'; echo "exit ${PIPESTATUS[0]}"
echo '$ worklog ticket hours ACME-7 1 --day 2026-10-15   (re-pin)'
$W ticket hours ACME-7 1 --day $D; echo "exit $?"
$W sync --day $D --dry-run --json | grep -E '"(timeSpentSeconds|issueId)"'; echo "exit ${PIPESTATUS[0]}"
echo '$ worklog ticket hours ACME-7 0.4 --day 2026-10-15   (must refuse, write nothing)'
$W ticket hours ACME-7 0.4 --day $D; echo "exit $?"
sqlite3 "$DB" "SELECT day, jira_issue, hours_override_seconds FROM tempo_line_texts;"
echo '$ worklog --json ticket hours ACME-7 --clear --day 2026-10-15'
$W --json ticket hours ACME-7 --clear --day $D; echo "exit $?"
sqlite3 "$DB" "SELECT count(*) AS rows_with_override FROM tempo_line_texts WHERE hours_override_seconds IS NOT NULL;"
```
