## Run 1 — found a defect (fixed by T007)
- Right-click header → menu, instruction typed, Enter → "Writing…" → after 10 s the toast
  "Rewrite failed — daemon request to /tempo/lines/redescribe timed out after 10000ms" (`CHK001-0-timeout-run1.jpg`).
  The box kept the instruction (FR-12b failure path). DB unchanged.
- Cause: `web/lib/daemonTimeout.ts` gave the new route the 10 s default. T007 gives it the 120 s of `/tempo/lines/regenerate`.
- Retries then hung for minutes: a stack sample showed the debug daemon blocked in
  `SecKeychainFindGenericPassword` (provider selector, Jira and Mirres secrets) — the new unsigned
  binary waiting on Keychain access. Environment, not this feature; fixed by the file secrets backend above.
- One direct `curl` with instruction "x" then returned 200 in 7 s (and a blank instruction returned 400
  `instruction is empty`); the DB was reset to the seed state before the final run.
